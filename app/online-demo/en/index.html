Text Search Engine · MIT

JavaScript Pinyin fuzzy search

Text Search Engine is a JavaScript and TypeScript npm library for searching local strings or objects in the browser or Node.js. A query can mix Chinese characters, full Pinyin, Pinyin initials, and English. Results include offsets into the original text for highlighting.

Install and run a quickstart

npm i text-search-engine

These examples were verified against npm release 1.6.2. The APIs are available from 1.6.0. Save the code as .mjs to run it in Node.js. The examples do not use React, but 1.6.2 declares a React 16.8, 17 or 18 peer: npm may install React 18 automatically, and existing React 19 projects can hit an install conflict.

1. Search an array by Pinyin initials

import { searchItems } from 'text-search-engine'

const [hit] = searchItems(['React', '监控平台'], 'jk')
console.log(hit.item, hit.hitRanges)
// 监控平台, [[0, 1]]

2. Match the title and hostname together

import { createSearcher } from 'text-search-engine'

const pages = [{ title: 'React 监控平台', host: 'github.com' }]
const searcher = createSearcher(pages, {
  getFields: ({ title, host }) => ({ title, host }),
})
const [hit] = searcher.search('jk github')
console.log(hit.fieldHitRanges)
// { title: [[6, 7]], host: [[0, 5]] }

3. Highlight matches in the original text

Continue from example 2. Ranges are inclusive UTF-16 offsets, so add 1 to the end for slice. In the browser, use textContent to fill a <mark> element rather than building HTML from raw text.

const [start, end] = hit.fieldHitRanges.title[0]
console.log(hit.item.title.slice(start, end + 1))
// 监控

Reuse the same createSearcher across keystrokes; rebuild it when the list, field text, or options change. Convert fields to strings and highlight the exact strings you passed in. Empty queries return []; render the original list yourself if desired. Results keep input order by default. Supply sort for your own relevance ranking.

Which to choose: Text Search Engine, pinyin-pro, or Fuse.js?

  • Text Search Engine：Choose it for an in-memory list where Pinyin, English, object fields, and original-text highlighting need to work together. It is not a full-text index or a general spell corrector.
  • pinyin-pro match：Choose it for matching individual strings or for transliteration, with your own list traversal and ranking. match() also returns positions; original-text highlighting is not unique to Text Search Engine.
  • Fuse.js + Pinyin：Start with Fuse.js if typo tolerance and field weights matter more. Add transliterated and initial fields for Pinyin search, and map offsets in those derived fields back to the original text if you need highlights there.
